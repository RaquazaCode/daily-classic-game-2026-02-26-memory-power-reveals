## Quick Start

```bash
pnpm install
pnpm dev
```

## How To Play

Click cards to reveal and match pairs.

## Rules

Match all regular pairs and use the power card strategically.

## Scoring

Matches gain points and misses reduce points.

## Twist

One power card reveals a hidden pair for a short time.

## Verification

```bash
pnpm test
pnpm build
```
